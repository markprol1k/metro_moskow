# Метро Москвы: кратчайший путь

**Автор:** Пролецкий Марк

Консольная программа, которая ищет самый быстрый маршрут между двумя станциями московского метро.
Схема метро хранится в `metro.json` в виде взвешенного графа: вершины — станции, рёбра — перегоны и пересадки, вес ребра — время в минутах.
Кратчайший путь ищется алгоритмом Дейкстры.

## Структура

| Файл | Назначение |
|---|---|
| `graph.py` | класс `Graph`: станции, рёбра, алгоритм Дейкстры, загрузка из JSON |
| `exceptions.py` | собственные исключения графа |
| `main.py` | консольный интерфейс (argparse) |
| `metro.json` | данные о станциях и перегонах |
| `test.py` | тесты на pytest |

## Станции

Станции с одинаковыми названиями на разных ветках подписаны веткой в скобках, например `Курская (Кольцевая)`.

**Сокольническая (красная):**
Фрунзенская — Парк культуры (Сокольническая) — Кропоткинская — Библиотека имени Ленина — Охотный Ряд — Лубянка — Чистые пруды — Красные Ворота — Комсомольская (Сокольническая) — Красносельская

**Арбатско-Покровская (синяя):**
Парк Победы (Арбатско-Покровская) — Киевская (Арбатско-Покровская) — Смоленская (Арбатско-Покровская) — Арбатская (Арбатско-Покровская) — Площадь Революции — Курская (Арбатско-Покровская) — Бауманская — Электрозаводская (Арбатско-Покровская)

**Кольцевая (коричневая), полностью:**
Проспект Мира (Кольцевая) — Комсомольская (Кольцевая) — Курская (Кольцевая) — Таганская (Кольцевая) — Павелецкая (Кольцевая) — Добрынинская — Октябрьская (Кольцевая) — Парк культуры (Кольцевая) — Киевская (Кольцевая) — Краснопресненская — Белорусская (Кольцевая) — Новослободская — Проспект Мира (Кольцевая)

**Люблинско-Дмитровская (салатовая):**
Марьина Роща (Люблинско-Дмитровская) — Достоевская — Трубная — Сретенский бульвар — Чкаловская — Римская — Крестьянская застава

**Пересадки:**
- Курская (Арбатско-Покровская) ↔ Курская (Кольцевая) ↔ Чкаловская
- Киевская (Арбатско-Покровская) ↔ Киевская (Кольцевая)
- Парк культуры (Сокольническая) ↔ Парк культуры (Кольцевая)
- Комсомольская (Сокольническая) ↔ Комсомольская (Кольцевая)
- Библиотека имени Ленина ↔ Арбатская (Арбатско-Покровская)
- Охотный Ряд ↔ Площадь Революции
- Чистые пруды ↔ Сретенский бульвар

Время перегонов и пересадок приблизительное.

## Запуск

Требуется Python 3. Команды выполняются из папки `metro_moskow`:

```bash
python -m main time --from "Арбатская (Арбатско-Покровская)" --to "Таганская (Кольцевая)"
python -m main path --from "Арбатская (Арбатско-Покровская)" --to "Таганская (Кольцевая)"
python -m main --from "Арбатская (Арбатско-Покровская)" --to "Таганская (Кольцевая)"
```

Команды:
- `time` — вывести только время в пути;
- `path` — вывести только маршрут (станции по порядку);
- без команды — вывести и время, и маршрут.

Аргументы:
- `--from` — станция отправления (обязательный);
- `--to` — станция назначения (обязательный).

Тесты:

```bash
python -m pytest test.py
```

## Сценарии

| Сценарий | Результат |
|---|---|
| Обе станции есть, путь существует | `time` — время, `path` — маршрут, без команды — оба |
| Станция отправления совпадает с назначением | время 0 и одна станция |
| Станции нет в схеме | `Ошибка: Нет станции: ...`, код выхода 1 |
| Между станциями нет пути | сообщение «Пути от … до … нет», код выхода 1 |
| Не указан `--from` или `--to` | подсказка argparse об обязательном аргументе |

Пример вывода:

```
Время в пути: 13 мин
Арбатская (Арбатско-Покровская)
Площадь Революции
Курская (Арбатско-Покровская)
Курская (Кольцевая)
Таганская (Кольцевая)
```
